# Mohammed Sahil R — Terminal Portfolio

Interactive terminal-style portfolio.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Upload `index.html`, `style.css`, `script.js`, and `resume.pdf` to a repository, then enable GitHub Pages from the repository's Settings → Pages.

## Commands

`help` `about` `skills` `projects` `aws` `terraform` `docker` `kubernetes` `cicd` `linux` `github` `resume` `contact` `neofetch` `clear`
